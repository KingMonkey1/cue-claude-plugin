---
name: cue-improve-prompt
description: Score or improve an AI prompt using Cue when the user requests prompt feedback or a rewrite.
---

Use Cue's improve_prompt tool with the user's selected draft. Report its actual score, feedback and rewrite. Preserve the user's intent and do not submit the rewritten prompt to another service or replace editor contents without instruction. A prompt score is not a factual-accuracy check or a guarantee about model output. If authentication or an allowance limit prevents the call, report that actual result and direct the user to reconnect Cue or review their plan at https://cue-prompt.com/pro. Never invent a tool result or request passwords in chat.
