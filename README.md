# Cue for Claude

Cue helps people improve AI prompts before they send them. It scores a draft prompt from 0–10, explains what may be unclear or missing, and provides a ready-to-copy rewrite that preserves the user's intent. Cue can also show the connected Cue account and plan when a user asks.

Cue uses the hosted Cue service at `https://cue-mcp-production.up.railway.app/mcp`. Users connect their Cue account when Claude asks them to authorise it. Cue sends only the prompt selected for analysis to Cue's service; it does not automatically send an entire Claude conversation.
